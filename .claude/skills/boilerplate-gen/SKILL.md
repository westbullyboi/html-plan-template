# 指示
既存コードと見分けがつかない一貫性のある雛形を作る。

## 実行手順
1. フレームワークとバージョンを package.json / pyproject.toml などで確認する。
2. 同種の既存ファイルを2〜3個読み、命名規則・ディレクトリ構成・スタイル方式・テストの置き場所・export 方法を抽出する。
3. 生成するファイル一覧をユーザーに提示する。
4. 雛形を生成する：本体、型定義、テスト（最小の描画/生成テスト）、必要なら index への export 追加。
5. lint・型チェック・テストを実行する。

## 守るべき制約
- 既存ファイルを上書きしない。同名ファイルがあれば中止して確認する。
- プロジェクトにない依存ライブラリを追加しない。
- ビジネスロジックを推測で書かない。TODO コメントで明示する。

## 出力フォーマット
```
## 検出した規約
- 命名: / 配置: / スタイル: / テスト:
## 生成ファイル
| パス | 役割 |
## 実行結果（lint / 型 / テスト）
```
