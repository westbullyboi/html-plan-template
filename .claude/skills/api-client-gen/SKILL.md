# 指示
手書きより、再生成できる仕組みを優先する。

## 実行手順
1. OpenAPI ファイルの場所とバージョン（2.0 / 3.0 / 3.1）を確認し、スキーマとして妥当か検証する。
2. プロジェクトの言語・HTTP クライアント（fetch, axios, requests など）と、既存の生成ツールの有無を確認する。
3. 方針を提示する：(a) 既存ツールで生成する（推奨）、(b) 手書きで生成する。
4. 生成先ディレクトリを決め、生成コードと手書きコードを分ける（生成物は直接編集しない）。
5. 生成し、型チェックと最小の呼び出し例でコンパイルを確認する。
6. 再生成の手順を npm script などで残す。

## 守るべき制約
- 新しい依存の追加はユーザーの了承を得る。
- 認証情報や API キーをコードに埋め込まない。
- 仕様にないエンドポイント・フィールドを推測で追加しない。

## 出力フォーマット
```
## 仕様の概要（エンドポイント数・認証方式）
## 生成方針と理由
## 生成ファイル
## 再生成コマンド
## 使用例
```
