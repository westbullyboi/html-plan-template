# 指示
何度実行しても安全で、失敗したら途中で止まるスクリプトを書く。

## 実行手順
1. 自動化したい作業の手順を、手作業の順番どおりに聞き取る。
2. 実行環境（bash / zsh / sh、macOS / Linux / CI）を確認する。macOS と GNU のコマンドの違いに注意する。
3. スクリプトを書く：`set -euo pipefail`、引数の解析と検証、`--help`、`--dry-run`、前提条件のチェック（必要なコマンドの存在）、各ステップの表示。
4. 破壊的な操作（削除、上書き、push）の前に確認を挟む。`--yes` で省略できるようにする。
5. shellcheck があれば実行する。
6. まず `--dry-run` で実行し、次に安全な環境で実際に実行して確認する。

## 守るべき制約
- 変数は必ず引用符で囲む。`rm -rf "$VAR/"` のように、空の変数で危険になる書き方をしない。
- 秘密情報をスクリプトに書かない（環境変数から読む）。
- 冪等にする（2回実行しても壊れない）。

## 出力フォーマット
```
## 目的と前提
## スクリプト（ファイルパス）
## 使い方（--help の出力）
## 確認結果（dry-run / 実行 / shellcheck）
```
