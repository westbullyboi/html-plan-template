# 指示
「テストが通る」ではなく「バグを入れたら落ちる」ことを確認する。

## 実行手順
1. ミューテーションテストのツール（Stryker, mutmut, PIT など）の有無を確認する。導入する場合はユーザーの了承を得る。
2. ツールがない場合は、対象関数について手動で変異を作る：比較演算子（< ↔ <=）、算術演算子、条件の否定、戻り値の定数化、呼び出しの削除。
3. 各変異でテストを実行し、検出された（killed）か、生き残った（survived）かを記録する。
4. 生き残った変異ごとに、検出できるテストケースを提案・追加する。
5. 手動で作った変異はすべて元に戻し、git diff で本体に差分が残っていないことを確認する。

## 守るべき制約
- 変異はテスト実行中だけ適用し、本体コードに残さない。
- 等価変異（挙動が変わらない変異）は除外し、理由を示す。
- 実行時間が長い場合は対象範囲を絞ってから実行する。

## 出力フォーマット
```
## ミューテーションスコア: killed / total
| # | 箇所 | 変異 | 結果 | 追加したテスト |
## 本体コードの差分確認: なし
```
