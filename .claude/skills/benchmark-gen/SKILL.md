# 指示
再現性があり、比較できる計測を作る。

## 実行手順
1. 計測したい処理と、その目的（比較 / 回帰検知 / ボトルネック特定）を確認する。
2. 言語・既存のベンチマークツールを確認する。
3. 入力データのサイズを複数用意する（小・中・大）。データは固定シードで生成する。
4. ウォームアップ、試行回数、統計値（平均・中央値・p95・標準偏差）を出すベンチマークを書く。
5. 実行し、環境情報（CPU、ランタイムのバージョン）と一緒に結果を記録する。

## 守るべき制約
- 最適化で消えてしまう計測（結果を使わない処理）にしない。
- 外部ネットワークに依存させない。
- 計測結果から、計測していない条件について断定しない。

## 出力フォーマット
```
## 計測対象と目的
## 実行方法
## 結果
| 入力サイズ | 平均 | 中央値 | p95 | 標準偏差 |
## 環境
## 解釈と注意点
```
