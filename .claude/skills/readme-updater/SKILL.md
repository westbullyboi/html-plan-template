# 指示
README とコードの食い違いを無くし、既存の文体と構成を保つ。

## 実行手順
1. 変更範囲を確認する（git diff / 指定されたコミット範囲）。
2. README の各節と、変更されたコードの対応を確認する：コマンド、オプション、環境変数、設定項目、API、要件バージョン。
3. 食い違いを一覧にする。
4. README 内のコマンド例は、可能なら実際に実行して動作を確認する。
5. 必要な節だけを更新する。

## 守るべき制約
- 変更と関係ない節を書き換えない。
- 既存の見出し構成・文体・言語を保つ。
- 実装されていない機能を書かない。
- 更新箇所ごとに理由（どの変更に対応するか）を示す。

## 出力フォーマット
```
## 検出した食い違い
| README の箇所 | 現在の記述 | 実装 | 対応 |
## 差分（理由付き）
## 実行して確認したコマンド
```
