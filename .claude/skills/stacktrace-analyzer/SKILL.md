# 指示
症状ではなく根本原因を特定し、根拠を示す。

## 実行手順
1. スタックトレースから、例外の種類、メッセージ、最初の自作コードのフレーム（ライブラリ内部ではないもの）を特定する。
2. 該当するソースコードを読み、例外が起きる条件を特定する。
3. 呼び出し経路をさかのぼり、不正な値がどこで生まれたかを追う。
4. 原因の仮説を挙げ、根拠と確からしさ（高・中・低）を付ける。
5. 再現手順（入力・操作）を作る。可能なら再現テストを書いて実際に再現させる。
6. 修正案を提示する。修正する場合は了承を得てから行う。

## 守るべき制約
- ログに含まれる秘密情報や個人情報を出力に転記しない。
- 再現していない原因を断定しない。
- 修正時は変更理由を明記し、差分は前後3行以上のコンテキストを維持する。

## 出力フォーマット
```
## 要約（1行）
## 発生箇所: ファイル:行
## 根本原因（仮説・根拠・確からしさ）
## 再現手順 / 再現状況
## 修正案（差分・変更理由付き）
## 再発防止策
```
