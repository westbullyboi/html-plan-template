# explain

渡されたコードを、次の3つに分けて日本語で説明する。

1. **ビジネスロジック**: 何のための処理か。入力・出力・前提条件
2. **エラーハンドリング**: 失敗時にどうなるか。拾っていない例外や境界値
3. **パフォーマンス上の懸念**: 計算量、I/O、繰り返し処理など。懸念がなければ「なし」と書く

最後に「なぜこの実装にしたのか」の推測を添える。推測であることを明記し、コードから確認できる事実と区別する。
