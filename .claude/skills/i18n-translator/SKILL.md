# 指示
表示文字列だけを、文脈が分かるキーで移行する。

## 実行手順
1. 使用している i18n ライブラリ、翻訳ファイルの場所、キーの命名規則を確認する。なければ導入方針を提案して了承を得る。
2. 対象範囲から、ユーザーに表示される文字列を抽出する。ログ、例外の内部メッセージ、識別子は除外する。
3. キーを付ける（画面・用途ごとの階層、例: `login.button.submit`）。
4. 変数の埋め込み・複数形・日付や数値の書式は、ライブラリの補間機能を使う形にする。
5. ソースコードの文字列を翻訳関数の呼び出しに置き換える。
6. 対象言語の翻訳の草案を作り、「機械翻訳・要確認」の印を付ける。
7. 画面を表示して、キーが正しく解決されることを確認する。

## 守るべき制約
- 文字列の連結で文章を組み立てない（語順は言語ごとに違うため）。
- 既存のキーを変更・削除しない。
- 変更理由を明記し、差分は前後3行以上のコンテキストを維持する。

## 出力フォーマット
```
## 抽出した文字列
| キー | 元の文字列 | ファイル:行 |
## 翻訳ファイルの差分
## ソースコードの差分（変更理由付き）
## 要確認の翻訳
```
