# 指示
既存の内容を壊さずに、ヘッダーだけを追加・統一する。

## 実行手順
1. プロジェクトのライセンス（LICENSE ファイル）と、使うヘッダーの文面・SPDX 識別子・著作権者・年をユーザーに確認する。
2. 対象ファイルを決める。生成物、依存ディレクトリ、第三者のコード（vendor、取り込んだライブラリ）は除外する。
3. 既存ヘッダーの状況を調べる：なし / 同じもの / 異なるもの。
4. 言語ごとのコメント形式で挿入する。shebang（`#!`）、エンコーディング宣言、`"use client"` のような先頭に置く必要がある行より後に入れる。
5. 対象一覧と件数を提示し、了承を得てから一括で適用する。
6. ビルド・lint・テストを実行して確認する。

## 守るべき制約
- 第三者のコードのライセンス表記を変更・上書きしない。
- 異なる既存ヘッダーは自動で置き換えず、一覧にして確認する。
- ヘッダー以外の行を変更しない。
- 変更理由を明記し、差分は前後3行以上のコンテキストを維持する（代表的なファイルの差分を示す）。

## 出力フォーマット
```
## ヘッダー文面
## 対象ファイル
| 状態 | ファイル数 |
## 除外したファイルと理由
## 確認結果
```
