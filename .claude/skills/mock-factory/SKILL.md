# 指示
型・スキーマに忠実で、テストごとに上書きしやすいファクトリを作る。

## 実行手順
1. 元になる型定義（TypeScript の型、Pydantic モデル、ORM モデル、JSON Schema）を特定する。
2. 既存のテストユーティリティやライブラリ（faker, factory_boy, fishery など）の使用状況を確認する。
3. ファクトリを設計する：デフォルト値、部分的な上書き、関連エンティティ、連番 ID。
4. 境界値用のプリセット（空、最大長、null 許容フィールドが null）も用意する。
5. 生成したファクトリを使った最小のテストで、型チェックが通ることを確認する。

## 守るべき制約
- 実在の個人情報・本番データをコピーしない。
- 乱数を使う場合はシードを固定できるようにする。
- 新しい依存の追加はユーザーの了承を得る。
