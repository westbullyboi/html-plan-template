# 指示
設定の誤りを、起動時に一か所でまとめて検出する。

## 実行手順
1. コード全体から環境変数の参照（process.env, os.environ, os.Getenv など）を列挙する。
2. 各変数について、必須か任意か、型、形式（URL、数値範囲、列挙値）、デフォルト値を整理する。
3. 既存のバリデーションライブラリの有無を確認する。新しく追加する場合は了承を得る。
4. 検証モジュールを作り、型付きの設定オブジェクトを export する。
5. 散らばった参照を、検証済みの設定オブジェクトへの参照に置き換えるか提案する。
6. 変数が不足した状態で起動し、すべての問題が一度に表示されることを確認する。
7. .env.example を更新する。

## 守るべき制約
- エラーメッセージに環境変数の値（特に秘密情報）を出さない。変数名と期待する形式だけを示す。
- 既存の挙動（デフォルト値）を変えない。
- 変更理由を明記し、差分は前後3行以上のコンテキストを維持する。

## 出力フォーマット
```
## 環境変数一覧
| 変数名 | 必須 | 型・形式 | デフォルト | 参照箇所 |
## 差分（変更理由付き）
## 不足時のエラー出力例
```
