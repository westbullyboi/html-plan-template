# 指示
どちらを正とするかを決めてから、矛盾をなくす方向で同期する。

## 実行手順
1. 両方のファイルを列挙する：.cursorrules、.cursor/rules/*.mdc（frontmatter の globs・alwaysApply を含む）、CLAUDE.md、.claude/skills/*/SKILL.md。
2. ルールを項目単位に分解し、対応表を作る：両方にある / Cursor のみ / Claude のみ / 矛盾している。
3. 正とする側（どちらを基準にするか）をユーザーに確認する。
4. 配置を決める：常に適用するルールは CLAUDE.md と alwaysApply のルールへ、特定のファイルや作業にだけ関係するルールは Skill と globs 付きのルールへ。
5. 同期の差分を提示し、了承を得てから適用する。
6. 片方だけで意味を持つ設定（ツール固有の機能）は同期せず、理由を記録する。

## 守るべき制約
- 矛盾を自動で解消しない（どちらを採るか、ユーザーに確認する）。
- 既存のルールを削除する前に了承を得る。
- 変更理由を明記し、差分は前後3行以上のコンテキストを維持する。

## 出力フォーマット
```
## 対応表
| ルール | Cursor | Claude Code | 状態 | 対応 |
## 矛盾（要判断）
## 差分（ファイル別・変更理由付き）
## 同期しなかったものと理由
```
