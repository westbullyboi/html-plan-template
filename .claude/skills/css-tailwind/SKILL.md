# 指示
見た目を変えずに移行し、テーマにない値は勝手に作らない。

## 実行手順
1. Tailwind のバージョンと設定（tailwind.config、テーマの拡張、プラグイン、v4 の場合は CSS 側のテーマ設定）を確認する。
2. 対象コンポーネントのスタイルを、プロパティごとに一覧にする。
3. 各プロパティを Tailwind のクラスに対応させる。テーマにない値は、(a) 最も近いテーマ値、(b) 任意値（`w-[123px]`）、(c) テーマへの追加、のどれにするか示す。
4. 疑似クラス、メディアクエリ、アニメーションの対応を確認する。
5. 置き換えたあと、可能なら変更前後のスクリーンショットを比較する。
6. 使われなくなった CSS を削除する（他から参照されていないことを確認してから）。

## 守るべき制約
- 見た目の変更を伴う置き換えは、明示して了承を得る。
- 他のコンポーネントから参照されている CSS を削除しない。
- 変更理由を明記し、差分は前後3行以上のコンテキストを維持する。

## 出力フォーマット
```
## 対応表
| セレクタ | プロパティ: 値 | Tailwind クラス | 備考 |
## 差分（変更理由付き）
## 見た目の確認結果
## 削除した CSS
```
